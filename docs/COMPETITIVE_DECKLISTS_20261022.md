## Consultation et export hors ligne

L'espace de ce lot est `data/local/public-campaigns/lot-i-competitive-20261022/`.
Il contient exclusivement les données publiques de ce lot; ne jamais y copier
une base personnelle. Les 32 textes prêts à consulter sont sous `exports/`, par
exemple `event-581-rank-1.txt` et `event-582-rank-1.txt`.

```powershell
python -m pokemind meta competitive-summary --db data/local/public-campaigns/lot-i-competitive-20261022/public.sqlite3 --json
python -m pokemind meta competitive-export --db data/local/public-campaigns/lot-i-competitive-20261022/public.sqlite3 --event 581 --placement 1
```

Ces commandes exigent un `--db` PUBLIC explicite; elles ne choisissent jamais
la base personnelle. Elles lisent hors ligne, sans modification du deck joué,
du presse-papiers ou du client. L'export réutilise `serialize_deck` et son
aller-retour PTCGL historique. Les 32 sorties ont été reparsées à 60 cartes.
La disponibilité des cartes dans le compte, la légalité actuelle TCG Live et
l'acceptation de ces nouvelles compositions dans le jeu ne sont pas attestées.
Le test de presse-papiers historiquement `FIELD_VALIDATED` n'a pas été refait.

Le script `scripts/import_competitive_pages.py` permet un réimport **hors ligne**
des corps déjà mis en cache, avec le même événement/date/échantillon. Il ne
télécharge rien, refuse les conflits et les migrations de cache existant.
La campagne réseau est close, même si son budget n'est pas épuisé.
