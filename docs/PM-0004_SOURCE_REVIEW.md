# Revue des sources PM-0004

Documentation officielle à vérifier : https://tcgdex.dev/rest et https://tcgdex.dev/reference/card.

L'API REST V2 fournit des listes de cartes et d'extensions et des objets détaillés; les langues fr/en ont une couverture variable. La présence d'une carte dans cette API ne prouve ni sa disponibilité dans TCG Live, ni la légalité Standard.

Codex devra mesurer couverture et qualité, vérifier les conditions de réutilisation et produire des tests prudents, sans conserver d'images ni publier les données locales.
