# Captures des thèmes BrainBall (synthétiques)

Rendues hors écran par les tests Qt, avec la fixture inventée des tests (« Invented Family », question et source
inventées) : aucune donnée personnelle. Foncé à gauche (ou en haut), clair à droite.

- `overview-coach.png` : vue d'ensemble et coach, 1280×860, bandeau de mise à jour visible.
- `pages-dark.png`, `pages-light.png` : Combats, Deck Lab, Cartes & méta (classeur), Apprentissage, Réglages
  (Général, Mises à jour), Terminal, fenêtre étroite 900×700.
- `overview-125.png` : vue d'ensemble à 125 % (`QT_SCALE_FACTOR=1.25`).
- `dialogs.png` : boîte de dialogue Qt dans les deux thèmes.
